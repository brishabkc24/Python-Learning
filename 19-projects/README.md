# Projects

These seven projects put the earlier topics together into small complete programs. Each one lives in its own folder with a `README.md` that explains what it does, which concepts it uses, how to run it and what a session looks like. Start with the easy ones and work down the table. Read the code, run it, then change it: every project README ends with ideas to extend it.

| Project | Folder | Concepts used | Difficulty |
|---|---|---|---|
| Number Guessing Game | [number-guessing-game](number-guessing-game/README.md) | `random`, loops, functions, input validation | Easy |
| To-Do List (command line) | [todo-cli](todo-cli/README.md) | menu loop, list of dictionaries, `json`, `pathlib` | Easy |
| Contact Book | [contact-book](contact-book/README.md) | `csv` module, custom exceptions, dictionaries of functions | Medium |
| Quiz App | [quiz-app](quiz-app/README.md) | `json`, `random.shuffle`, `zip`, scoring, tuples | Medium |
| Student Management System | [student-management](student-management/README.md) | classes, `sqlite3`, properties, dataset seeding | Medium |
| Calculator (Tkinter) | [calculator-gui](calculator-gui/README.md) | Tkinter class, `grid`, events, `messagebox`, exceptions | Medium |
| Chat App | [chat-app](chat-app/README.md) | sockets, threads, locks, client and server | Hard |

## Before you start

- Every project runs with the standard library only. No installation is needed.
- Run each project from inside its folder, for example `cd 19-projects/todo-cli` and then `python todo.py`. Data files are created next to the script.
- The menu-driven programs accept bad input without crashing. Try typing letters where a number is expected.
- Press Ctrl+C at any time to stop a program.
