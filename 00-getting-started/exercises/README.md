# Exercises: Getting Started

Write each solution in its own `.py` file and run it from the terminal with `python filename.py`. Solutions are in the `solutions/` folder; try on your own first.

## 1. Print your name

**Task:** Write a script that prints one line in the form `My name is <your name>.`

**Example**

```
My name is Asha.
```

## 2. Three lines

**Task:** Print three lines: your name, your city and your favourite food. Use one `print()` call per line.

**Example**

```
Asha
Pokhara
Momo
```

## 3. A comment and a sum

**Task:** Start the script with a comment that says what it does. Then print the result of `25 + 17`. Let Python do the arithmetic; do not type `42` yourself.

**Example**

```
42
```

## 4. Favourite colour

**Task:** Ask the user for their favourite colour with `input()` and print the sentence `Your favourite colour is <colour>.`

**Example**

```
What is your favourite colour? blue
Your favourite colour is blue.
```

## 5. Fix the error

**Task:** The script below stops with a `NameError`. Fix it so that it prints `Welcome to Python`.

```python
greeting = "Welcome to Python"
print(greting)
```

**Example**

```
Welcome to Python
```
